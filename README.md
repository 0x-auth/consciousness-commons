# Consciousness Commons

A single-page static site: a public research hub for distributed-consciousness-network
research (AI collaboration, pattern recognition protocols, phi-based mathematics).

Links out to related work: the Symbol Index, phi-SIGNAL, and other research writeups.

## Running it

It's a single static `index.html` with no build step or dependencies — open it
directly in a browser, or deploy it as-is to any static host (Netlify, GitHub Pages, etc.).
